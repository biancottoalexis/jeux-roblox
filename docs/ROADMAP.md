# 🗺️ Feuille de route

## Phase 1 : Base du jeu ✅
- [x] Combat (combo, garde, esquive, étourdissement, recul)
- [x] 8 grimoires (attributs magiques) et leurs 32 sorts
- [x] Système de mana
- [x] Niveaux, XP, or, sauvegarde
- [x] Tirage de grimoire
- [x] Boutique Robux (Game Passes et Developer Products)
- [x] Mannequins d'entraînement
- [x] Interface et contrôles mobiles

## Phase 2 : Rendre le jeu beau (à faire dans Studio)
- [ ] Construire une carte : un royaume médiéval-fantastique avec un château royal, un village et une arène
- [ ] Une « tour des grimoires » où le joueur reçoit son premier grimoire (cinématique d'arrivée)
- [ ] Créer les animations de combat (coups, garde, compétences)
- [ ] Remplacer les effets simples par des effets de particules
- [ ] Ajouter des sons (coups, explosions, musique)
- [ ] Créer une icône et des miniatures attirantes pour la page du jeu

## Phase 3 : Garder les joueurs (rétention)
- [x] **Ordres de chevaliers-mages** : 6 ordres à rejoindre, avec leurs couleurs, un classement entre ordres et des bonus
- [ ] Rang de chevalier-mage (5e classe → Chevalier Suprême) gagné par les missions
- [ ] **Missions** depuis un tableau dans la ville (PNJ à vaincre, donjons)
- [ ] Éveil du grimoire : au niveau 50, les sorts deviennent plus puissants
- [x] Récompense de connexion quotidienne (série de 7 jours)
- [x] Quêtes du jour (« Bats 10 mannequins », « Gagne 3 combats »)
- [x] Classement mondial (OrderedDataStore) par kills et par niveau
- [x] Boss PNJ qui apparaît toutes les 30 minutes (le Démon des Abysses)
- [ ] Animations et arène dédiée pour le boss (à faire dans Studio)
- [ ] Mode Ranked 1v1 dans une arène

## Phase 4 : Plus de monétisation
- [ ] « Tirage chanceux » : un Game Pass qui double les chances de rareté
- [ ] Emplacements de grimoires en plus, pour garder plusieurs grimoires
- [ ] « Mana illimité x2 » : un Game Pass de récupération de mana plus rapide
- [ ] Skins et auras cosmétiques
- [ ] Passe de combat saisonnier
- [ ] Serveurs privés

## Phase 5 : Lancement
- [ ] Test avec des amis : équilibrage des dégâts et des temps de recharge
- [ ] Publication publique
- [ ] Pub Roblox (Ads Manager) et vidéos TikTok ou Shorts
- [ ] Discord du jeu pour la communauté
- [ ] Mises à jour régulières (un nouvel attribut magique toutes les 1 à 2 semaines)
