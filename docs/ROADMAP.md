# 🗺️ Feuille de route

## Phase 1 : Base du jeu ✅
- [x] Combat (combo, garde, esquive, étourdissement, recul)
- [x] 6 styles et leurs 24 compétences
- [x] Niveaux, XP, Yens, sauvegarde
- [x] Spins de style
- [x] Boutique Robux (Game Passes et Developer Products)
- [x] Mannequins d'entraînement
- [x] Interface et contrôles mobiles

## Phase 2 : Rendre le jeu beau (à faire dans Studio)
- [ ] Construire une carte : un village japonais et une arène, avec la Toolbox ou en modélisant
- [ ] Créer les animations de combat (coups, garde, compétences)
- [ ] Remplacer les effets simples par des effets de particules
- [ ] Ajouter des sons (coups, explosions, musique)
- [ ] Créer une icône et des miniatures attirantes pour la page du jeu

## Phase 3 : Garder les joueurs (rétention)
- [ ] Récompense de connexion quotidienne
- [ ] Quêtes (« Bats 10 mannequins », « Gagne 3 combats »)
- [ ] Classement mondial (OrderedDataStore) par kills et par niveau
- [ ] Boss PNJ qui apparaît toutes les 30 minutes
- [ ] Mode Ranked 1v1 dans une arène

## Phase 4 : Plus de monétisation
- [ ] « Spin chanceux » : un Game Pass qui double les chances de rareté
- [ ] Emplacements de styles en plus, pour garder plusieurs styles
- [ ] Skins et auras cosmétiques
- [ ] Passe de combat saisonnier
- [ ] Serveurs privés

## Phase 5 : Lancement
- [ ] Test avec des amis : équilibrage des dégâts et des temps de recharge
- [ ] Publication publique
- [ ] Pub Roblox (Ads Manager) et vidéos TikTok ou Shorts
- [ ] Discord du jeu pour la communauté
- [ ] Mises à jour régulières (un nouveau style toutes les 1 à 2 semaines)
